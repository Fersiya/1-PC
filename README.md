# LumaLink — Сервер подсветки для Windows

Беспроводная синхронизация цвета монитора с умной лампой через смартфон (`ПК → Wi-Fi → LumaLink Android → Bluetooth → Лампа`).

## Сборка единого EXE на GitHub
1. Загрузите файлы из этой папки в корень репозитория GitHub (включая `.github/workflows/build-pc.yml`).
2. Перейдите во вкладку **Actions** → **Build LumaLink Windows EXE** и скачайте артефакт **`LumaLink-Windows`** (`LumaLink.exe`).
